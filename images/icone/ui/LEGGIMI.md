# Icone di interfaccia

Icone del set **Tabler Icons** (https://tabler.io/icons), licenza MIT, versione 3.50 (ottobre 2026).
File originali in questa cartella; nel sito sono incorporate come `mask-image` in `css/style.css`
(variabili `--ico-*`), così prendono il colore del testo e non richiedono richieste aggiuntive.
Nomi Tabler: phone, car, map-pin, clock, calendar-event, mail, circle-check.
